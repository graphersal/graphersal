# Graph layer (`graph/`)

Agent guidance for storage, units, change capture, catalog, compression, indexes and permissions. Schema: `graph/schema/CLAUDE.md`. Persistence: `persist/CLAUDE.md`. Not packaged.

## Storage and handles

- `TraversalGraph` (`graph/mod.rs`): `Topology` (`graph/topology.rs`, own slot store replacing petgraph's `StableGraph` with its exact observable behaviour: stable indices, LIFO free lists, linked adjacency lists newest first, self-loop in both lists; capacity control `reserve_exact`/`shrink_to_fit`, exact vacant counts; model test `random_operations_match_a_plain_model`) + property maps + indexes (`graph/index.rs`). No petgraph dependency. A load reserves the slots from the manifest counts (`PersistentStorage::reserve_load`) and every load ends in `shrink_to_fit` (no spare slots). `Graph<S = TraversalGraph>` (`graph/shared.rs`) is a lock newtype over `parking_lot::RwLock<S>` (`read()`/`write()`/`try_write()` -> `GraphRead`/`GraphWrite` deref to `S`; no `parking_lot` type in the API).
- `AnyGraph` (`graph/any_graph.rs`, `graphersal::storage`, EXPERIMENTAL): the sealed dyn boundary front ends hold (`Arc<dyn AnyGraph>` via `IntoAnyGraph`), blanket for `Graph<S>` with `S: Default + Send + Sync + 'static`, one coarse operation per method (identity/capabilities/statistics/memory, seven schema methods, catalog incl. `set_definitions`, `mark`, io, `write_snapshot`, with `script` `run_plan`/`run_unit`).
- The pipeline is generic over `GraphStorage` (`graph/storage.rs`, EXPERIMENTAL in 0.1.x; its trait rustdoc is the implementer's guide), implemented for `TraversalGraph`, `&mut`/`Box`/`Arc` wrappers, the read-only view `&G` (`&` and shared `Arc` claim no capabilities) and a test-only `MockStorage`. Conformance suite: `graphersal-storage-tests`.
- Id index (`graph/index.rs`): `hashbrown::HashTable<(handle, u32 FNV hash)>`, the id stored once (in the weight); lookups take the graph and confirm against the slot (generation + id), removal by handle, growth from the cached hash. Invariant and layout: `GraphIndex` docs, book `for_developers/storage_internals.md`.
- Handles (`graph/handle.rs`): `VertexHandle`/`EdgeHandle` = slot + `NonZeroU32` generation, no public constructor. A handle to a removed element never aliases: reads are "removed" (`contains_*` false, no properties, empty adjacency, filters drop it), `id()`/`label()`/materialization/writes fail with `GraphError::ElementRemoved` (deviation, `dropping_elements.md`), a second drop is a no-op. A new handle-taking method validates through `resolve_vertex`/`resolve_edge` or `vertex_weight(_mut)`/`edge_weight(_mut)`.
- Steps carry lazy handles (`TraverserValue::Vertex`/`Edge`, `VertexProperty`/`EdgeProperty`, `Record { keys: Arc<..>, values }`); `size_of::<TraverserValue>()` stays 64.
- A vertex has a label SET (`Vec<CompactString>`, ordered, deduplicated; empty = unlabeled); the first is primary (`vertex_label()`/`label()`/`elementMap()` single-valued like TinkerPop), `vertex_labels()`/`labels()` the full set. Edges have one label; `GraphStorage::set_edge_label` (checked under the new label; `UndoEntry::EdgeLabel`, `Mutation::SetEdgeLabel`, WAL op 11).
- **Property shapes** (`graph/shape.rs`, `value/property_map.rs`; book `for_developers/storage_internals.md`, keep it in sync): every stored map is `PropertyMap(Repr::Shaped { shape: Arc<Shape>, values: Vec<ElementProperty> })` (values exact when built or grown, a removed key's slot kept as capacity); the `ShapeTable` (`TraversalGraph::shapes`, a `hashbrown::HashTable` by key-sequence hash) interns key sequences without allocating on a hit (the last shape tried first). Lookup: `KeyPrint` (len + first/last 8 bytes, exact up to 16 bytes) scan for <= 16 keys, an `IndexSet` above: no `memcmp` per candidate. Transitions `(shape, position, key)`/`(shape, position)` in `MixHasher` maps (never FNV over words: it cost more than the transition) behind one-entry memos. Choke points: `insert_vertex_raw`/`insert_edge_raw` `adopt` every entering map; in-graph key-changing writes go through `shapes.insert_full`/`shift_remove_full`/`shift_insert` (`with_vertex_map`/`with_edge_map` split the borrow), a generic-helper write (jpath) re-`adopt`s. A shape carries its table's id (adopt = one compare); a foreign shape is re-interned (memo `last_foreign`). Snapshot chunks decode maps `Shaped` directly (`persist::codec::ChunkShapes`, by key-reference sequence; no `IndexMap`). The importers do too: GraphSON/GraphML collect keys and values in a `MapBuilder` (`shape.rs`; a repeated key = `insert`'s first position/last value, merged at `finish`) interned in importer-own tables (one per element kind; the graph adopts via `last_foreign`, any storage takes them); change sets copy each added map with `TraversalGraph::stored_copy` (`ShapeTable::shaped_copy`, own table) in `TraversalGraph::apply_change_set` (override of the default's body `apply_change_set_with`) and every replay path, other storages clone (`replay::clone_map`). Tests `import_shape_tests.rs`, `shape.rs` `import_tests`; benches `imports::*`. Sweep (drops shapes only the table holds; clears caches and memos) on table doubling, `shrink_to_fit`, loads; never under `&self`. Free-standing maps stay `Indexed` (hot paths match `Indexed` first, the `Shaped` arm out of line); a key change through the public API converts a `Shaped` map to `Indexed`. The trait is unchanged. Tests `shape.rs`, `property_map.rs` `shaped_tests`/`key_print_tests`, `codec.rs` `chunk_shape_tests`, `property_order_tests.rs`, `property_shape_tests.rs`; benches `element_properties::*` (incl. `insert_build`, `bulk_build`, `get_key`).
- **Insert vs add:** `insert_vertex`/`insert_edge` are the required primitive (store exactly what is given, coercing + validating; imports, change sets, replay, loads, copies use them; never generate a value). `add_vertex`/`add_edge` (never override) create like a query: the override point `add_vertex_with`/`add_edge_with(.., &CreateContext)` applies schema create-time defaults, then calls `insert_*` (conformance `add_applies_schema_defaults_insert_does_not`).

## Custom storages

A host's `GraphStorage` (+ `Default + Send + Sync + 'static`; `PersistentStorage` to be stored) runs under every generic front end; book `for_developers/custom_storage.md` (example `crates/graphersal-session/tests/custom_storage_example.rs`, included by anchors). Engine monomorphised per storage; one dyn boundary per layer: `AnyGraph` (script, saved queries), `SessionGraph`/`SessionStore`/`GraphFactory` (session), crate-internal `StoreGraph` (Store). `TraversalGraph`-only: script scratch graphs (`GraphSource::*`, `__`, `_g`, `subgraph`/`cap`/`toGraph`), a `withSideEffect` subgraph target, compressed properties (`recompress` `Unsupported` elsewhere), the undo log, merge checkpoint/salvage/repair working graphs, the shipped front ends. An unimplemented operation is `GraphError::Unsupported { operation }`. Proof storage `Forwarding`: `foreign_storage_tests.rs`, `generic_persist_tests.rs`, `foreign_store_tests.rs`, session `storage/tests.rs`, TinkerPop with `GRAPHERSAL_TEST_STORAGE=forwarding`.

## Units (undo log)

- `begin_unit() -> UnitMark` / `commit_unit(mark)` / `rollback_unit(mark, &RollbackReason)`; units nest (inner = savepoint); defaults are no-ops (non-atomic storage). `TraversalGraph`'s private undo log (`graph/undo.rs`) records inverses (string ids and element images, never handles; old value with position, old label set, old schema) and replays them in reverse via raw helpers (`insert_vertex_raw`, `remove_vertex_raw`, `insert_edge_raw`, `remove_edge_at`), restoring structure, indexes, statistics, schema (not iteration order; new handles; auto-id sequences never rolled back).
- One unit each: every traversal (`run()` and every terminal inside `GraphTraversalSource::atomically`; a failing traversal leaves nothing, deviation `transactions.md`), `set_schema` and a catalog change outside a unit, a live GraphML/GraphSON import, `apply_change_set`. Loading an unpublished graph (`from_graphml`, `from_graphson`, `GraphSONImport::load`, `TraversalGraph::replay`) runs outside units (`load_outside_units`). Direct trait calls outside a unit record nothing (conformance `mutation_outside_unit_records_nothing`).
- `Transactional` (`graph/transaction.rs`, blanket, prelude + `storage`): `transaction(|g| ..)`/`transaction_with(CommitMetadata, ..)` (panic rolls back; `E: From<GraphError>` carries a veto; nested metadata merged via `set_unit_metadata`, outer wins), `dry_run(|g| ..) -> (T, ChangeSet)` (always `discard_unit`: no hooks, `commit_seq` 0; needs `change_capture`). `unit_changes(mark) -> UnitChanges { data, schema, definitions }` makes `Execution::mutated()`/`changes()` right inside an outer unit.
- Panic safety: a unit unwinding rolls back first (`graph::storage::close_on_unwind`; every opener uses it, a new one too). `commit_undo_unit` covers the commit once: a panic while deriving the change set or in `before_commit` rolls back, sends `after_rollback`, resumes; a panic in `after_commit` leaves it committed.
- **A new mutating `GraphStorage` method of `TraversalGraph`** records an `UndoEntry` only when it changed something, keeps statistics exact, and gets a case in `graph/capture.rs`.

## Change capture and hooks

- `ChangeSet`/`Mutation` (`graph/change.rs`, public, `#[non_exhaustive]`, `compact()`, serde behind `serde`): one committed unit: `commit_seq`, `committed_at` (i64 µs, `web_time::SystemTime`, monotonic `max(now, previous)`; 0 for a dry run), `node_sequence`/`edge_sequence` AFTER the unit, `CommitMetadata`, mutations in order with before/after values (cascaded `DropEdge`s before their `DropVertex`; a jpath write is a `SetProperty` of the top-level key; `SetSchema` in the same stream).
- Built at the outermost commit only while a hook is registered, by `derive_mutations_since` (`graph/capture.rs`: backwards walk of the undo log over a shadow), so nothing is paid without hooks.
- Hooks (`graph/hooks.rs`, `CommitHook`): `before_commit` may veto -> rollback + `GraphError::CommitRejected { hook, source }` (help from a `HookRefusal { message, help }` or `PersistError` source), `after_commit`, `after_rollback`; `register_commit_hook` (default `Unsupported`, never removable); registration order, `commit_seq` order, only the `ChangeSet`. Empty units emit nothing, except a sequence-only commit (`raise_id_sequences`).
- Foreign code: `ChangeSet::builder(seq, at)` (`build()` -> `GraphError::InvalidChangeSet`), one constructor per `Mutation` kind, embedded public `CommitHooks` (ordering contract documented there; `set_journal(JournalSlot)`).
- `last_commit_seq()` + an export under one read lock = a snapshot with position; `with_last_commit_seq(n)`. `apply_change_set` (one captured, vetoable unit) then raises id sequences (`raise_id_sequences`, never lowered); `TraversalGraph::replay(self, &ChangeSet)` raises seq, time and sequences. Counters never wrap: `GraphError::SequenceOverflow` (rolled back).
- Serde of a `ChangeSet` tags non-JSON types per value (`g:UUID`, `gx:OffsetDateTime`/`gx:ZonedDateTime`/`gx:OffsetTime`/`gx:LocalDate`/`gx:LocalDateTime`/`gx:LocalTime`/`gx:Duration`/`gx:Period`/`graphersal:Interval`, `graphersal:Vector`, user objects with `"@type"` escaped as `graphersal:Object`; strict reading; `value/physical.rs` `Tagged`/`TaggedOwned`). GraphML and the rest of the codec stay untagged.
- `StorageCapabilities` (`graph/capabilities.rs`, facts not permissions; `TraversalGraph`: `atomic`, `change_capture`, `writable`): `change_capture` requires `atomic` (debug assertion in `GraphTraversalSource::new`). Docs `book/src/users_guide/transactions.md`.

## Statistics and memory

- `GraphStorage::statistics() -> Option<&GraphStatistics>` (`graph/statistics.rs`): totals, vertex counts per label and per primary label, edge counts per label. `TraversalGraph` maintains them in the raw helpers + every label-set change; a new mutation path updates them too (`statistics_tests.rs`, compared with `GraphStatistics::from_storage`). The executor reads label counts only here and scans on `None`. Limits never go in (session `Session::statistics()` = `{statistics, memory, limits}`).
- `memory_usage() -> Option<MemoryStats>` (`graph/memory.rs`, trait method, default `None`): on-demand footprint (`structure_bytes`/`index_bytes`/`property_bytes` (incl. `shape_bytes`: each shape once; a stored map counts its value slice), compression and `property_index_bytes` fields); unrelated to execution. Profiling memory: `traversal/CLAUDE.md`.
- Memory report (`graph/memory_report/`, facade `storage`, book `memory_and_profiling.md`): `GraphTraversalSource::memory_report(&MemoryReportRequest)` (Read on Data, `CancelToken` -> `Cancelled`) runs `walk::compute`, ONE generic walk over the read API (labels, maps, degrees, `property_indexes()`, `compression_stats()`): rows per `(kind, primary label, top-level key)` = `PropertyTarget` (shared with the planned workload statistics), aggregated by shape pointer (memo; `Indexed` maps by key), HLL distinct strings (`hll.rs`), stratified sampling per label (first element always read, scale = seen / read). Storage-only part: trait `memory_structure() -> Option<StructureMemory>` (default `None`; `Forwarding` deliberately does not forward it). Invariant tested: `MemoryReport::property_bytes() == memory_usage().property_bytes` for `TraversalGraph`. Forms: `to_property()`/`to_json()` (`property.rs`, the one map every front end shows), `Display` (`text.rs`, REPL `/memory`). Tests `memory_report_tests.rs`.

## Catalog (`graph/definition.rs`, book `saved_queries.md`)

- `Definition` = `DefinitionKind` (u8: `QUERY` 1, `PROPERTY_INDEX` 2, `COMPRESSION` 3, 4-127 unassigned, 128-255 HOST kinds: `DefinitionKind::host(n)`, stored `Opaque`, never damage) + `DefinitionFlags` (bit 0 critical, others kept) + name (unique per kind) + `DefinitionBody` (`Query(QueryDefinition)` | `Opaque(Vec<u8>)`, kept byte for byte).
- `QueryDefinition`: folder, description, dialect (`QUERY_DIALECT` `graphersal-rhai/1` reads, `WRITING_QUERY_DIALECT` `/2` may write its inferred effects, `GQL_QUERY_DIALECT` / `GQL_WRITING_QUERY_DIALECT` `graphersal-gql/1|2` the same for a GQL body; `language()` derives `rhai`/`gql` from it; the script layer sets it on save, the core keeps what it is given), source (one Rhai function or one GQL query), ordered `QueryParam { schema, default }`, meta, `extra`. Effects are derived, never stored (no `writes` field; `script/CLAUDE.md`). `Definition::validate` (every `set_definition`) checks names (identifier, no Rhai keyword), folders, sizes (`MAX_*`), param names (not `RESERVED_PARAM_NAMES`, defined here), schemas, defaults (`QueryParam::check_value`); never compiles the source.
- Forms: `to_payload`/`from_payload`, `to_json`/`from_json`, `catalog_to_json`/`catalog_from_json` (lenient), `definition::encode_payload`/`decode_payload` (feature `persist`), `QueryParam::from_value` (strict). Trait `definitions`/`definition`/`set_definition`/`remove_definition`; `Catalog` (max `MAX_DEFINITIONS`), `UndoEntry::Definition`, `Mutation::SetDefinition`. Rust: `list_definitions`, `get_definition`, `set_definition`, `define_query`, `remove_definition`, `move_query`, `describe_query`. DSL: `script/CLAUDE.md`.
- Persisted (`persist/definitions.rs`, spec 6.3, 9.3, 16): record `kind | flags | name | length | payload`, WAL op 10; payload keys never `kind`/`name`/`flags` (`RESERVED_PAYLOAD_KEYS`); a payload that is not a valid property map is damage, a valid map is NEVER damage (spec 16 rule 9): fields `from_payload` cannot read keep the definition OPAQUE (`DefinitionRecord::decode_in`); a journal vetoes storing a critical opaque definition. **Forward-compat rule:** an unknown VALUE of a known key a newer version may add (compression `codec`/`element`/unparseable `path`: `CompressionDefinition::foreign`, `unserved_reason`, `codec_name`/`element_name`; index `type`/`transform`/`element`; saved-query `params`: `QueryDefinition::unsupported_reason`, payload form only, the exchange form stays strict) is kept as read, written back unchanged, not served/applied/run, listed with `served: false` + `reason`, refused on create by front ends; tests `forward_compat_tests.rs`. Tests `definition_tests.rs`, `definition_store_tests.rs`, conformance `definitions_are_stored_validated_and_removed`, `rollback_restores_definitions`, `definition_changes_are_captured`.

## Compressed properties (`value/compressed.rs`, `graph/compression.rs`, book `compressed_properties.md`)

A rule is a catalog definition of kind `compression` (`CompressionDefinition`: element, label, jpath of names, lz4, `min_bytes`, `dictionary`). Strings at rule paths are stored as the STORAGE-ONLY `ElementProperty::Compressed(Box<CompressedText>)` (verified round trip when made, reads infallible). It never leaves the graph: every read goes through `ElementProperty::logical`/`to_logical`/`with_text`/`text` (and `From` to `TraverserValue`, `into_node_property`, both codecs, `Mutation::make_logical`); equality/hash/order are logical. **A new read site uses them; a new exhaustive match treats `Compressed` as a string** (out-of-line helpers keep frames small: the 2 MiB test stack is tight). Invariant (`check_compression_invariant`): compressed iff at a rule path, `>= min_bytes` and `<= 90 %`; kept by the write path (`CompressionRules::prepare_*`), `compression_after_change`, `recompress`, rollback and `compression_load_pass`. `lz4_flex` is non-optional. Tests `compressed_property_tests.rs`.

Codec `dedup` (issue #13, `Codec::Dedup`): a qualifying string (`dedup_qualifies`: `>= min_bytes` and longer than the inline `CompactString`, 24 bytes) is the STORAGE-ONLY `ElementProperty::Deduped(DedupedText)` (`value/deduped.rs`, an `Arc<str>`), pointing to the one copy in the rule's `DedupTable` (`Rule::dedup`, `Arc<parking_lot::Mutex<..>>`: the write path normalizes under `&self`). It follows the `Compressed` contract everywhere (`holds_compressed()` is true for both); the invariant also requires the reference to BE the table's copy (`adopt` canonicalizes restored values). Unreferenced entries are swept lazily (table doubled since the last sweep, outermost rollback, `recompress`, load). Per-codec defaults through `Option` fields of `CompressionDefinition` (`min_bytes` 25, no dictionary; `dictionary: true` is a field error). Stats/estimate count each distinct text once as `len + DEDUP_ENTRY_OVERHEAD` (32); dedup candidates are exact (never sampled) and not in `CompressionCandidate::defaults()` (asked by codec, or the current rule). `MemoryStats::dedup_table_bytes` counts each table once inside `property_bytes`. Tests `compression_dedup_tests.rs`.

Estimate (`graph/compression_estimate.rs`, issue #12): `TraversalGraph::estimate_compression(&CompressionEstimateRequest)` is read-only (no unit, no catalog change) and measures `CompressionCandidate`s (codec + options; a new codec is a new `Codec` variant and an arm in its candidate loop) with the rule's OWN code: the dictionary via `dictionary_from` over `compression_elements` (id order), qualification via `CompressedText::compress`, bytes counted like `compression_stats`. Keep it that way: `compression_estimate_tests.rs` asserts estimate == `compression_stats` after defining each candidate (below the caps; above them a deterministic every-k-th sample is extrapolated). Trait `GraphStorage::estimate_compression` (default `Unsupported`), `GraphTraversalSource::estimate_compression` (Read on `Data{element, label}`, cancellation -> `TraverserError::Cancelled`), `AnyGraph`, DSL `g.estimate_compression(#{..})`, session/MCP/HTTP/wasm/Python.

## Property indexes (`graph/property_index.rs`, book `property_indexes.md`, `optimizer/property_index.md`)

- `(element, label, key) -> value -> elements`, catalog kind `property_index` (`PropertyIndexDefinition`, facade `catalog`; vertices and edges; a multi-label vertex is in every index of its labels). Entries are never persisted: every mutation path and undo keeps them exact, define/drop rebuilds one, `finish_load` all.
- Keys: logical scalars with `has()`'s exact equality (numbers by float64, temporal values, a `datetime` by instant, compressed strings by text); arrays/objects/vectors never indexed. Trait `property_indexes`/`vertices_by_property_index`/`edges_by_property_index` (may return more, caller re-checks). DSL `create_index`/`drop_index`/`indexes`.
- `type` (`PropertyIndexType`, default `memory-ordered`, always written; `holds(&ValueType)` is the one type matrix). Unknown types/transforms are kept byte for byte, never built or served (`served: false` + `reason`), refused on create. Creation front ends run `check_create` against the stored schema (`DefinitionError::IndexTypeMismatch`); `set_definition`/replay/loads never do.
- Transform `to_lower` (`PropertyIndexTransform`): keys lowered strings only via `step_to_lower::lower_text`; serves `has(key, __.to_lower().is(P))` (`filter_steps/step_has_traversal.rs`, `index_condition`) only while `PropertyIndexStats::skipped` is 0; lookups `*_by_transformed_property_index`; default name appends `_to_lower`. Tests `property_index_tests.rs`, `has_traversal_tests.rs`.

## Permissions (`graph/authorization.rs`, book `permissions.md`)

- `Authorizer::authorize(&AccessRequest) -> Result<(), Denied>` + `resolve_file(path)`. Request = `Action` (`Read`/`Create`/`Update`/`Delete`/`Execute`/`Custom`) x `Resource` (`Data { element, label }`/`Schema`/`Definition { kind, name }`/`File { path }`/`Option { key }`/`Embedder { name }`/`Custom`; never produced by the library). The subject lives in the authorizer; no roles.
- **Everything is allowed by default** (`AllowAll`; `restrictions` `None`). `AccessPolicy`: bit table, `allow_all()`, `deny_all()`, `read_only()` (Read on Data+Schema+Definition, Execute on Definition), `allow`/`deny`/`*_resource`, `with_file_root(dir)`. `with_authorizer(a)` (options set before are host presets).
- The check (`traversal/permission_check.rs`, `Restrictions::check`) runs once per execution in `run()`, BEFORE the optimizer, on the plan as written incl. children: extra requests, administrative `g.with()` keys (`ADMIN_OPTION_KEYS` -> `Update` on `Option`), every step's `GraphStep::for_each_access_in` with the `AccessFlow` the steps before it state (`access_flow_after`: element kind, and labels only where complete per element: edges, `add_v(labels)`; a vertex `has_label` states the kind only; children start empty), so `property`/`drop`/label steps name their elements; a denied step is located by address; each distinct request once; no per-element checks. Denial = `TraverserError::PermissionDenied { step, request, reason }`, located like a failing step.
- Script entry and private graphs: `script/CLAUDE.md`. CLI and Python allow everything, the playground `allow_all().deny_resource(File)`. **A new step touching files or the schema, or a new administrative option, needs its requests.**
