# Schema (`graph/schema/`)

Agent guidance. User docs: `book/src/users_guide/schema_enforcement.md`. Not packaged.

- **One format everywhere** (Rust, Rhai, Python, playground): our envelope outside, a strict subset of JSON Schema 2020-12 inside. Envelope `{"$schema": "https://graphersal.dev/schema/v1" (SCHEMA_FORMAT_URL, optional), "meta": {free, never interpreted}, "mode": "none"|"open"|"closed" (default none), "vertices": {label: {"schema": <object node>}}, "edges": {label: {"connections": [{"from", "to"}], "schema": ..}}}`; `$defs`/`$schema`/`$id` only at a label schema's root. Unknown keys/keywords are errors everywhere (`SchemaError::InvalidSchema { path (JSON Pointer), reason, hint }`). The empty schema is no schema (`set_schema({})` clears). Meta-schema `graphersal-schema-v1.json` (`META_SCHEMA_JSON`).
- Node `PropertySchema` (`node.rs`): `type` (string or array; `integer` = `int64`, `number` = `float64`; `string`+`format` `uuid` / `date-time`/`date`/`local-date-time`/`time`/`duration` (`SchemaFormat`); `array`+`format: vector` with `element`/`dimension`/`metric`/`embedder` = `VectorSchema` (no `items`; `embedder` = model identity, top-level only, read by vector rules and text queries, never checked by a plain write, never inferred; diff kind `embedder_changed`; `from` = the VECTOR RULE (book `vector_rules.md`, runtime `graph/vector_rules.rs`): top-level only (`misplaced_vector_keyword`), needs `embedder`, no chains, source must admit a string (`vector_rules::check_rule_structure`, run by `check_defaults`); `set_schema_recorded` checks the model (`hash-ngram/1` or a catalog model, `VectorRuleModelMissing`) and declares a missing `dimension`; diff kinds `vector_rule_added`/`_changed`/`_removed` (`embedder_changed` only for rule-less properties); `SchemaValidation.fill`/`SchemaDiff.fill` = `PlannedFill`s, `schema::fill_warning` the ONE warning text)), `items`, `properties`, `required`, `additionalProperties` (bool only), `anyOf`; constraints `minimum`/`maximum`/`exclusive*`/`minLength`/`maxLength`/`pattern`/`minItems`/`maxItems`/`enum`/`const`, temporal `formatMinimum`/`formatMaximum`/`formatExclusive*` (must fit the declared type); annotations `title`/`description`/`$comment`/`examples`/`deprecated`; `default`/`defaultFunction` (`uuidv4`/`uuidv7`/`now`/`today`). Local `$ref: "#/$defs/X"` inlined at load (cycles rejected). `parse.rs`: `from_json`/`from_value`/`to_value`/`to_json` (canonical order); builders on `PropertySchema`/`GraphSchema`.
- **Create-time defaults** (`defaults.rs`, rules in the `Annotations` rustdoc): applied only when an element is CREATED (`add_v`/`add_e`, `mergeV`/`mergeE` on create, `add_vertex`/`add_edge`), only to missing TOP-LEVEL properties, only in `open`/`closed`, before coercion/validation; never on read, never re-applied, no backfill; `default: null` never stored; imports, change sets, replay, loads and `insert_*` never apply them. `uuidv*` per element; `now`/`today` ONE value per unit (`unit_started_at`, unless pinned by `CreateContext`/`with_now`/`script::pin_now`); recorded as a plain value. `check_defaults` requires a valid default and `defaultFunction` at top level only (`now` on `date-time`, `today` on `date`); saved-query param schemas reject `defaultFunction`.
- `ValueType` (`types.rs`): `Null`, `Boolean`, `Int64`, `Float64`, `String`, `Uuid`, `Date`, `LocalDateTime`, `DateTime`, `Time`, `Duration`, `Vector(..)`, `Array`, `Object`, `Union`. Diagnostics name types via `type_name`/`non_null_type_name` (`int64`, `union<int64|null>`), never JSON Schema names.
- Inference (`inference.rs`, `SchemaInferer`): exact logical type per position (type arrays, `anyOf` for string+uuid, `required` only for keys every object has), never guessed from content; mode `none`, valid for its data in `open`/`closed`.
- Enforcement (`validation.rs`, `nested.rs`, `coerce.rs`): in `Open`/`Closed` a declared property coerces on write (canonical string -> `uuid`/temporal, `date-time` only with explicit offset/zone; `int64` -> `float64`); validation compares logical types exactly; reads never coerce. `required` and nullability are independent. `mode` is the default `additionalProperties` of `object` nodes (explicit wins, `admits_additional_properties`); `Closed` also rejects undeclared labels and checks topology. Multi-label: each label checks what it declares; an undeclared key is allowed if ANY label admits it; coercion follows the first declaring label; topology accepts an edge if any label of each endpoint matches (`*` all). `check_removal` rejects removing a required property; label add/remove validates the new set first. A `Vertex`/`Edge` value is never a property (`InvalidPropertyValue`).
- Apply (`apply.rs`): `get_schema`/`set_schema` (default `Unsupported`), `declared_property_schema`. `Open`/`Closed` scan the data once (`scan_storage_change`: only the labels whose declaration changed when the stored schema has the same mode, `changed_labels`; else `scan_storage`, all; the preview `validate_schema` scans the same and times it for `PlannedFill::scan_ms`) and fail with aggregated `ExistingDataViolatesSchema` (groups, counts, sample ids, `[*]` paths, `ViolationGroup::example_field`; same walker as writes via a `Sink`; nothing changed); `None` applies without scanning. "Freeze what you have": `set_schema(infer_schema(), mode)` always applies to its data, except `Closed` with unlabeled elements (`UNLABELED`; `schema_freeze_tests.rs`). `SchemaMode::parse` is the one error for an unknown name. A schema change is a database change (`Mutation::SetSchema`, seq, rollback, `UnitChanges.schema`).
- Seven methods on `GraphTraversalSource` (Rhai both spellings, Python, wasm): `get_schema`, `set_schema`, `patch_schema` (`patch.rs`, RFC 7396 on the canonical form), `validate_schema`/`validate_schema_patch` (`SchemaValidation`), `infer_schema`, `diff_schema` (`diff.rs`: compatible = backward compatible: only adds or relaxes; removing a declaration from an open object relaxes; tightening or removing a label or a closed object's key is incompatible; `default_changed` always compatible). Authorization: Read Schema; `set`/`patch` Update Schema. Stream step `infer_schema()` (Rust `infer_schema_step()`). In Rhai a schema is a plain map (`script::schema_of_value`).
- `meta_graph.rs` (`to_graph`/`subgraph`), `visualize.rs` (table/markdown/tree, mermaid, plantuml, per-label JSON Schema, json).
- Tests: `schema_gap_tests.rs`, `schema_freeze_tests.rs`, `transaction_tests.rs`.
