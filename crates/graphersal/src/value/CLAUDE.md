# Values (`value/`)

Agent guidance for value types, tokens, temporal values, vectors, embedders and jpath keys. Not packaged.

- `ElementProperty` (stored values) and `TraverserValue` (stream values). Serde of `ElementProperty` is plain JSON via the physical codec (a `Uuid` is its string); only `ChangeSet` serde adds type tags.
- `PropertyMap` (`property_map.rs`, element properties) and `StreamMap<S>` (`stream_map.rs`, `TraverserValue::Object`: `group()`, `tree()`) are newtypes keeping `indexmap`/`fnv` out of the API. `StreamMap` is `#[repr(transparent)]` (crate code uses `.0`); `PropertyMap.0` is `Repr::Indexed(IndexedMap)` (the `IndexMap` boxed and allocated on the first write, reads of an unallocated one see a static empty map; so `size_of::<PropertyMap>()` = 32, the `Shaped` size) | `Repr::Shaped` (graph-stored, shared key list: `graph/CLAUDE.md` "Property shapes", book `for_developers/storage_internals.md`): crate code uses the `pub(crate)` positional helpers (`insert_full`, `shift_remove_full`, `get_full`, `shift_insert`, `insert_if_absent`, `indexed_mut`), never assumes a representation; `Debug`/`Eq`/serde are identical for both.
- `Number`, `Path`, `Predicate` (`P.*`), `GType` (incl. `DATETIME`/`DATE`/`LOCALDATETIME`/`TIME`/`OFFSETTIME`/`DURATION`/`VECTOR`), `Operator`, `Barrier`, `Column` (`select(Column::Keys/Values)`; a map and a map entry `TraverserValue::Entry` (only from `unfold()` of a map) are distinct: a list for a map, the scalar for an entry), `cast.rs` (`as_string`/`as_bool`/`as_number`), `json_path.rs`, `uuid.rs`.
- `element_value.rs` (`VertexValue`/`EdgeValue`/`VertexRef`, untyped GraphSON 3 JSON, book `vertex_and_edge_values.md`), `record_key.rs` (`RecordKey` `Name`/`Id`/`Label`/`Out`/`In`, keeps `T.id`/`T.label`/`Direction.*` apart from properties named `id`/`label`, book `id_and_label_keys.md`).
- `physical.rs`: the physical (JSON types) codec, `lower` logical -> physical, `lift` by declared `ValueType`; the ONLY place values cross the I/O boundary (root rule 14). Non-finite floats: value JSON (`to_json_text`/`write_json_typed`, `TypedFloats` for the `json` visualizer) writes GraphSON's `{"@type":"g:Double","@value":"NaN"|"Infinity"|"-Infinity"}` (output only, never read back by the untyped readers); `write_json` (GraphML) and the plain serde of `ElementProperty` stay strict (error). The session applies the same form via `display::json_safe` (book `displaying_results.md`).
- `literal.rs`: Rhai literal text for rendering (`TokenLiteral`, see `script/CLAUDE.md`).

## Temporal (`temporal/`, book "Dates and Times" `book/src/dates/`, facade `graphersal::temporal`)

`Date`/`LocalDateTime`/`DateTime`/`Time`/`OffsetTime`/`Duration` as `ElementProperty::Temporal(Temporal)`: plain integers, `Copy`, 1 ns (temporal v2), years -9999..9999; a `DateTime` keeps its offset (and, when written with one, an IANA zone name as `zone::ZoneId`, a `NonZeroU16` index into the sorted name table built once from `jiff::tz::db().available()`; `zone_name()`, `in_zone`, `from_local_in`, `without_zone`; `with_offset` drops the name) but compares by instant (the name never compared, `Temporal::bits()`, the exact key, includes it); an `OffsetTime` (`TemporalKind::OffsetTime`, `offsettime`, `GType.OFFSETTIME`, schema `format: "offset-time"`, `gx:OffsetTime`) is an i64 of local ns + offset, compares by `utc_nanos()` (not wrapped); arith: a zoned `DateTime` computes in its own zone when no zone argument is given and the result keeps the name (`arith::zone_of`); a zone argument wins and the result carries ITS name when it is an IANA zone, none for a fixed offset (temporal v2 stage 5, user decision; `at_zone` uses `at_named`/`resolve_named`); `Zone::resolve`/`at` give no name (internal wall-clock helpers), `resolve_named`/`at_named` keep it; persist file format 3 stores both (tags 17, 19; the zone as its NAME, never the `ZoneId`); a `Duration` (months/days i32, time part ns within `Duration::MIN_NANOS..=MAX_NANOS` = an i64 of seconds + 0..1e9 ns, the `java.time.Duration`/Neo4j range; temporal v2 stage 2b) compares field by field. Nanoseconds over the range do not fit an i64: `LocalDateTime`/`DateTime`/`Duration` hold a private `Nanos96` (three 32-bit words, alignment 4, `get() -> i128`), so `Duration` is 20 bytes, `Temporal` 24, `ElementProperty` 32; `Time` an i64 of ns. The micros accessors (`micros()`, `epoch_micros()`, `micros_of_day()`, `microsecond()`) cut below the µs (instants round down, a duration toward zero); `Duration::micros()` is `Option<i64>` (`None` beyond an i64 of µs, never a cut; Rhai getter `micros` a range error; persist file format 3 stores the whole range); `Temporal::has_sub_micros()` tells a value with digits below it: the Python binding returns those as `pandas.Timestamp`/`pandas.Timedelta` (extra `graphersal[pandas]`, else `ImportError`; a time of day `ValueError`), never cuts (persist file format 3 keeps ns; the µs tags 9-13 of format 2 are read only). Text: fraction in groups of 3/6/9 digits, 1-9 digits read exactly. IANA zones via `jiff` (bundled tzdb, same everywhere incl. wasm32; no `jiff` type in the API). `dt.rs` = the `DT` token. DSL `as_date`, `date_add`, `date_diff`, `age` (PostgreSQL), `date_trunc`, `date_part`, `at_zone`, `as_local`, globals `now()` (evaluation start, pinned by `script::pin_now`) and `today([zone])`. The clock is in ns (`graph::undo::now_nanos`, `defaults::system_now`; `GraphStorage::unit_started_at() -> Option<i128>` ns): the digits the platform gives (macOS µs, wasm32 ms via `Date.now()`), never invented; commit / journal / Store stamps stay µs (`now_micros`). A string never becomes temporal implicitly: only by a schema `format`, a type tag or an explicit step.
GQL-only helpers (Neo4j semantics the openCypher TCK measures; never called by the date steps, Rhai text unchanged): `parse::parse_extended` (every ISO 8601 form: basic, week, ordinal, quarter, short times, fractions on any duration unit, the alternative duration form; reports `zone_name`; an `OffsetTime` text without an offset is UTC), `arith::{cascade, scale_duration}` over `Amount` (exact nano-units, month = 30.436875 days), `arith::between_neo4j`, `format::neo4j` (the `toString` text), `civil::{from_iso_week, week_year_start, from_ordinal, from_quarter}`.

## Vectors (`vector/`, book `users_guide/vectors.md`, facade `graphersal::vector`)

- `ElementProperty::Vector(Vector)`: own type, `Arc`-shared immutable; 1..=65536 components, never NaN/inf; elements `f32`/`f16`/`i8` (code x one f32 scale)/`bit`; `quantize`/dequantize; `half.rs` own binary16 (no `half` crate). Kernels `similarity.rs` (cosine, dot, l2, hamming, f64 accumulation, fixed 8-lane order = deterministic); JSON forms `tagged.rs`.
- Formats: persist tag 14 (file format 2), `ChangeSet` tag `graphersal:Vector`, physical codec/GraphSON export as a plain list (import reads the exact tag), GraphML only through a declared schema. Never a property index key.
- DSL: `vector([..][, kind])`, `GType.VECTOR`, `as_vector()`/`quantize(kind)` (`map_steps/step_vector.rs`), `similarity([key,] q[, metric])`, `nearest(key, q, k[, #{metric}])` (exact top-k, no ANN), `vector_mean()`; the schema's `metric` is the default.

## Embedders (`vector/embed/`)

- Trait `Embedder` (`Send + Sync`, `info()`, `embed(&[&str], &EmbedContext)`, optional `memory_bytes()` (default `None`; `Model2Vec` reports rows x cols x 4 + the tokenizer file; read by the session's process memory report), batched, synchronous; `ctx.check()` = cancel/deadline). `EmbedderInfo` (`#[non_exhaustive]`: `name`, `model` identity, dimension, element, metric, `max_batch`, `deterministic`, `local`). `EmbedError` (one `help()` arm per variant; constructors `unavailable`/`failed`/`bad_output`/`no_features`; in a traversal `TraverserError::Embed`, a cancel becomes `Cancelled`/`Timeout`). Registry `Embedders` (immutable; `Default` = built-in `HashNgram` `hash-ngram/1`; `builder().with(..)?.default_name(..)?.build()`; names `[A-Za-z0-9._\-/:]` <= 128 bytes, models also `@?=`; `hash-ngram*` reserved; `get`, `by_model`, `infos`).
- **`hash_ngram.rs` is FROZEN** (golden bits `tests/data/hash_ngram_golden.rs`, shared with `graphersal-wasm/tests/embed_parity.rs`); a change is `hash-ngram/2`.
- Wiring: `with_embedders` (none: process default); `run()` binds every embed step BEFORE the permission check (`bind_embedders`: `embedder_request`/`bind_embedder`/`embedder_name`); `map_steps/step_embed.rs` uses the executor's batch path (`batch_size`/`process_batch`, chunks of `max_batch`, bulk kept), renders `embed("name", embedder: "hash-ngram/1")`. Scripts: `ScriptAccess.embedders` (`set_engine_embedders`, `set_scope_embedders`); session `SessionPresets::embedders`; CLI `cli::embedders()`. DSL step `embed()`/`embed(key)`/`embed([key,] #{embedder})`, global `embed(text[, #{embedder}])`, `g.embedders()`. Permission: `Execute` on `Resource::Embedder { name }` for every embedder; `read_only()` allows it. No embedder runs in replay/recovery/loads.
- Job `embed_property` (`vector/embed/job.rs`, `EmbedJob`/`EmbedReport`/`EmbedJobError`): `Graph::embed_property(job, embedders, cancel, progress)` (+ `AnyGraph`) collects ids (read lock), per page reads texts (read lock), embeds WITHOUT a graph lock, writes one `transaction` per page re-reading each text (`skipped_changed`/`skipped_removed`); `NoFeatures { index }` skips that text; failure keeps earlier pages; `only_missing` (default) resumes. Inside an open unit or `EmbedJob::run_in(&mut S, ..)` everything runs under one lock, pages = savepoints. DSL `g.embed_property(#{label, from, to, element?, embedder?, only_missing?, batch?})` asks Read+Update Data, Execute Embedder, Update Schema only when it declares; denied in a saved query.
- Provenance (`provenance.rs`): needs an ATTACHED schema (open/closed, `SchemaNotAttached`), never attaches one; declares an undeclared `to` (vector + `embedder: model`) or adds `embedder` in the first page's unit; refuses another model (`EmbedderMismatch`), a non-vector or other dimension (`TypeMismatch`); another element kind quantizes.
- Text queries `nearest(key, "text", k)`/`similarity(key, "text")` (`VectorQuery::Text`): bind candidate embedders per model the schema declares for the key (`text_query_candidates`; refusals `SchemaNotAttached`, `NoDeclaredEmbedder`, `TextQueryKey`, `ModelNotRegistered`), Execute on each candidate, each element's model picks one (`ModelConflict`), text embedded ONCE per execution, a `bit` property quantizes the query.
- `model2vec` feature (`embed/model2vec.rs`, `cfg(all(feature = "model2vec", not(target_arch = "wasm32")))`, never in wasm): loads a LOCAL directory only (never network) via `model2vec-rs` (no default features) + `tokenizers` (`fancy-regex`, pure Rust: **no `cc`/C/C++, keep it so**) + `safetensors`. `Model2Vec::load(name, dir)` / `options().with_max_tokens(..).with_normalize(..).with_max_batch(..).load(..)`; the load checks the shape and every vocab id against the rows; every call into `model2vec-rs` under `catch_unwind` -> `EmbedError::Failed`; load failures `Unavailable` with the `graphersal embed-model download <repo>` hint; an all-zero mean is `NoFeatures`. Info: model dimension, F32, cosine, `max_batch` 256, `deterministic: false`, `local`. Identity `model2vec/<repo>@<12 hex>` (repo from `graphersal-embed-model.json`, `MANIFEST_FILE`) or `model2vec@<12 hex>`: SHA-256 of `model2vec-identity/1\n` + `<role> <size> <sha256>\n` per file, never a path (`model_identity(dir)`); a differing normalize adds `?normalize=..`. Own SHA-256 `embed/sha256.rs` (no SHA crate). Tests `model2vec_tests.rs` (`a_real_potion_model` `#[ignore]`, needs `GRAPHERSAL_EMBED_MODELS`).

## Property keys (jpath, `prop_key.rs`, book `jpath_keys.md`)

A step taking a property name takes `impl Into<PropKey>` (`PropKey::Name` | `PropKey::Path(JsonPath)`; `PropKeys` for lists); the Rhai binding takes a string or `jpath("a.b[1]")` (RFC 9535 singular query, `[-1]`, bracket names). **A plain string is always a literal name, never parsed.** A path builds a separate step (`step_has_path.rs`, `step_values_path.rs`, `prop_path.rs`, `PathKeys`) exposing no `keys()`/`labels()`/`ids()` (no optimizer folding), reading by reference (`descend_property`), cloning only the leaf. A missing path is absent, never an error. `properties(jpath)` yields `TraverserValue::PathProperty`. Writes/removals via `set_*_property_path`/`remove_*_property_path` (defaults on a copy; in place only with `SchemaMode::None`); nested validation in `graph/schema/nested.rs`; faults `GraphError::InvalidPropertyPath { fault: PathWriteFault }`; a removal never errors on a bad path. **A new name-taking step accepts a `PropKey` in both spellings** or says why in its `///`.
