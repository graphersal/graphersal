# Playground

Agent guidance for the static browser playground (Vue, no bundler). It runs `graphersal-wasm` in a Web Worker; `playground/build.sh` builds it into `playground/pkg/` (git-ignored, goes stale: rebuild after engine/DSL/session changes). The dev server embeds `index.html`, `css/`, `js/`, `assets/`, `reset/` only. See `playground/README.md`: its "Graph drawing" section holds the measured Cytoscape tuning and layout timings.

- Top bar **Catalog ▾** (`js/components/catalog.js`, models `js/compression.js`, `js/indexes.js`, `js/saved-queries.js`, `components/saved-queries.js`) lists the catalog's kinds with counts, opens their managers (Saved queries, Compression, Property indexes) and holds the one catalog file (`graphersal-catalog-<stamp>.json`). Saved queries are managed and run only there (the Query panel has no Saved menu); the run form writes `g.query(..)` into a tab. The editor's Rhai / GQL switch (`language` in the spec only for GQL; GQL highlighting `js/editor/gql-language.js` over the pure tokenizer `js/editor/gql-tokens.js`); the tab menu's "Save as query…" (`saveTabAsQuery` -> `openCatalog('save-as-query')`, model `draftFromScript`/`parseGqlCall`: one `g.gql(..)` call becomes a GQL draft with its `$params`).
- Store: every Store menu/dialog action (`store-menu.js`) runs through `runStoreTask` (`js/store.js`, `state.storeTask`): one at a time, shown on its button (`components/store-task-label.js`), on the top-bar Store button and in a live region (texts `STORE_TASKS` in `js/store-model.js`). The WebAssembly playground shows it on its store in memory too.
- Highlighter token classes: `js/editor/token-classes.js` (fallback + what `tokenValues()` reports).
- Query panel "+" opens a Query or an **AI Chat** tab (tab kind `ai` in `js/tabs.js`; model + per-tab controller `js/ai-chat.js`: own conversation, `after` cursor and poll loop per tab, `/clear` and `/help` local; view `components/ai-chat.js`; answers through the own safe Markdown renderer `js/markdown.js` + `components/markdown-view.js`, never HTML). Works only with the dev server's `--ai`; read-only in the WebAssembly playground.
- Schema panel infers only on first show and its refresh button (`js/schema/panel-sync.js`): a graph change re-reads only the stored schema and otherwise shows "may be outdated - refresh"; a replaced graph (`state.graphEpoch`) is inferred once when shown.
- Change feed: `js/change-feed.js` polls `GET /api/changes` and reloads on changes it did not make.
- Graph drawing: model `js/graph-data.js`; drawings go through the renderer interface `js/graph/renderer.js` (two tiers: Cytoscape is Detailed, `js/graph/cytoscape-renderer.js`; sigma.js + graphology on WebGL is Fast, `js/graph/sigma-renderer.js`; cdnjs UMD scripts with SRI injected on first use). **Never call a drawing library from a panel.** `js/graph/tiers.js` picks the tier (size with hysteresis, Auto/Detailed/Fast, no-WebGL fallback) and derives banner and disabled controls from `capabilities`; `js/graph/controller.js` picks the layout (Cytoscape's own up to 200 vertices, else the engine's; always the engine's in Fast) and swaps renderers keeping positions; toolbar Stop cancels layouts via `js/graph/layout-jobs.js`; label colours `js/graph/palette.js`. Result highlight and its Clear/Esc dismissal: `js/graph/highlight.js`. Long values (inspector, Results table) collapse through `js/value-view.js` + `components/value-text.js` (setting `valueMaxChars`).
- Query panel **Examples** (`components/examples-panel.js`, model `js/examples-panel.js`): an overlay drawer (never a docked panel), opened by click or a 300 ms hover; plain substring search over titles and scripts, collapsible groups, last opened example and scroll restored (localStorage via `util.js` `storage`). Examples carry `group` and an optional `subgroup` (the GQL group is split): Rust tests (`graphersal-wasm`'s `playground_*examples*`, which filter `group == "GQL"`) and the MCP examples resource read `group` only, so keep `group: "GQL"` on every GQL example; groups and subgroups stay contiguous in the file (checked by `tests/examples-panel.test.mjs`).
- Links: `js/link.js` format `#/play?graph=..&q=..&run=1` (the book's run buttons use it).
- Tests: `node --test playground/tests/*.test.mjs`. Serve with `python3 playground/serve.py 8000` (no-store caching).
